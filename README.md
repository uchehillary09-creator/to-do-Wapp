# To-Do List

A task manager built with vanilla HTML, CSS and JavaScript.

## Features
- Add, edit, complete and delete tasks (full CRUD)
- Priority levels (low, medium, high) shown as a coloured edge
- Filter by All / Active / Done, and clear completed tasks
- Saved in the browser with `localStorage`, so tasks survive a refresh
- Keyboard friendly (Enter to save, Escape to cancel an edit) and follows your system dark mode

## Run locally
Open `index.html` in a browser, or use the VS Code "Live Server" extension.

## Concepts practiced
Arrays (`filter`, `find`, `unshift`), `localStorage` with JSON, event listeners, DOM rendering, form handling.
